Оцени качество идеи для продуктового бэклога OTA-компании:

Название: {title}
Проблема: {problem}
Решение: {solution}
Домен: {domain}

Критерии (каждый 0-2 балла, итого max 10):
1. Конкретность: есть ли конкретное действие? ("внедрить X" vs "изучить Y")
2. Привязка к продукту: понятно ли, какой компонент/экран/API затронут?
3. Обоснование: есть ли связь с исходным сигналом?
4. Реализуемость: можно ли это сделать силами одной команды за квартал?
5. Ценность: описана ли ценность для пользователя или бизнеса?

Верни ТОЛЬКО JSON (без markdown, без комментариев):
{
  "quality_score": <0-10>,
  "criterion_scores": {"конкретность": <0-2>, "привязка": <0-2>, "обоснование": <0-2>, "реализуемость": <0-2>, "ценность": <0-2>},
  "issues": ["<проблема, если score < 2 по критерию>"],
  "improved_title": "<улучшенный title, если текущий слишком абстрактный>",
  "improved_solution": "<конкретизированный solution, если текущий -- 'изучить'>",
  "pass": <true если quality_score >= 6, иначе false>
}
