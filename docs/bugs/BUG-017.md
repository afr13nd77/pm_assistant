# BUG-017 — _inject_source_file: footer wikilink не инжектируется

**Severity:** minor
**Компонент:** knowledge-engine
**Файл:** knowledge-engine/app/meeting_fetcher/fetcher.py, строка ~225
**Обнаружен:** 18.06.2026
**Связь:** BL-133

## Observed behavior
Функция `_inject_source_file()` не добавляет wikilink на raw-файл в footer протокола. Инжекция frontmatter (`source_file:`) работает корректно.

Footer ищет паттерн `*Источник: транскрипт Яндекс Телемост*`, но Claude не всегда включает эту строку в генерируемый протокол, несмотря на наличие паттерна в промпте (meeting_protocol.txt:54).

## Expected behavior
Каждый протокол должен содержать wikilink на исходный raw-файл:
```
*Источник: [[raw/inbound/.../transcript.txt|исходный файл]]*
```

## Steps to reproduce
1. meeting_fetcher обрабатывает email-транскрипт
2. Claude генерирует протокол БЕЗ строки `*Источник: транскрипт Яндекс Телемост*`
3. _inject_source_file() не находит паттерн → пропускает инжекцию footer
4. Протокол сохраняется без wikilink на raw-файл

## Root cause
Зависимость от конкретной строки в LLM-выводе ненадёжна. Claude не гарантирует точное воспроизведение footer из промпта.

## Fix
Если паттерн footer не найден — добавить строку-ссылку на raw-файл в конец протокола (append fallback).

## Status: fixed
